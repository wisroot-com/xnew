# three.js の影の詰め方 — bias で自己影を消さない

> DirectionalLight の影は `bias` を上げれば縞（shadow acne）は消えるが、
> 同時に細かい凹凸の自己影も消える。bias で殴らず、shadow map の精度を上げてから
> bias を最小にするのが順序。かつての 2_addons/three_table（卓のモデルは xnew-gamelab へ移した）の
> ボクセルキャラで実際に踏んだ話。

## 症状

キャラクターの凹んだ箇所（髪の張り出しの下、体の凸パーツの脇）に影が落ちない。
床に落ちる影は正常なので「影が出ていない」わけではなく、**自己影（self-shadow）だけが消えている**。

原因は `shadow.bias = -0.0005`。bias は「遮蔽物の深度を光源側へずらす」処理なので、
**ずらす量が凹みの深さを超えると、その凹みは自分自身に遮られていないと判定される**
（peter-panning）。ボクセル 1 個が 1.5cm 程度のモデルに対して bias が ≒5.7mm もあった。

## 数字の見積もり方

`shadow.bias` は shadow camera の深度空間（near..far を 0..1 に正規化）で効く。
つまり**ワールド単位でのずれは `bias × (far - near)`**。

| | 変更前 | 変更後 |
|---|---|---|
| `mapSize` | 2048² | 4096² |
| 視錐台（Orthographic） | ±2.5（5 単位） | ±2.0（4 単位） |
| → 1 テクセル | 2.4mm | **0.98mm** |
| `near` / `far` | 0.5 / 12（11.5 単位） | 3 / 9（**6 単位**） |
| `bias` | -0.0005（≒ **5.7mm**） | -0.0001（≒ **0.6mm**） |

acne の出やすさは「1 テクセルの大きさ × 面の傾き」でほぼ決まるので、
**テクセルを細かくすれば必要な bias も比例して小さくできる**。
深度レンジ（near..far）を詰めるのも同じ効き方をする — 同じ bias 値でも
ワールド単位のずれが小さくなる。

## 手順

1. **視錐台を被写体ぎりぎりまで絞る。** `left/right/top/bottom` は影を落とす対象の
   外接範囲まで。ここが一番効く（範囲を半分にすればテクセルは半分）。
2. **`near` / `far` も詰める。** 光源からの距離 ± 被写体の半径で十分。
   `near: 0.5, far: 100` のような広いレンジは bias をそのぶん効きづらくする。
3. **`mapSize` を上げる。** 4096² は 64MB。ライト 1 個なら許容範囲だが、
   1 と 2 をやらずにここだけ上げるのは効率が悪い。
4. **最後に bias を最小値まで下げる。** 上を詰めた後なら -0.0001 程度で acne は出ない。

## normalBias は万能ではない

`normalBias` は法線方向にサンプル位置をずらす（ワールド単位）。平らな受光面の acne には
bias より副作用が少なく有効だが、**ずらす量が形状のディテールより大きいと結局自己影が消える**。

あの卓では 0.002（2mm）でもボクセルの凹みの影がはっきり弱まったため使っていない。
目安は「ディテールの最小サイズの 1/10 以下」。1.5cm のボクセルなら 1.5mm が上限で、
それだけ入れても acne 対策としてはほとんど効かない。**細かいモデルには視錐台を絞る方が先**。

## そのほか

- `THREE.PCFSoftShadowMap` は deprecated（内部で PCFShadowMap にフォールバックし、
  コンソールに警告が出る）。新規は `PCFShadowMap` を指定する。
- shadow camera のプロパティを書き換えたら `dir.shadow.camera.updateProjectionMatrix()` を忘れない。
- 影を落とす / 受ける指定は両方要る。読み込んだモデルは
  `scene.traverse((obj) => { if (obj.isMesh) { obj.castShadow = true; obj.receiveShadow = true; } })`。

## 未対応

`wip/cat_king` は 40x40 の床を ±5 の視錐台 / 2048 / bias -0.0005 で照らしており、
同じ peter-panning が起きているはず。ただし床が広く視錐台を絞れないので、
同じ値をそのまま持ち込むと acne 側に振れる。直すならカスケードか、
影を落とす範囲をテーブル周辺に限定するのが先。
